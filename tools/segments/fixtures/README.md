# Transcript fixtures

Small excerpts only — a handful of cues each, never a whole transcript. They
exist to pin the *grammar* each publisher stack emits, not to mirror any
episode's content. Each file's header comment records which stack it models and
which quirk it is here to defend against.

Word content is paraphrased/invented; the timestamp shapes, header lines, cue
settings, index conventions and JSON key names are the real, load-bearing part.

Counts that motivated the four formats, measured across the 208 live feeds in
this catalogue: `text/vtt` 7063, `application/srt` 6848, `application/json` 787,
`application/x-subrip` 621.
